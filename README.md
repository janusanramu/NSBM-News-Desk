# NSBM-News-Desk

## MySQL database

The project database schema and starter news categories are in [`database.sql`](./database.sql). Import it using phpMyAdmin (select **Import** and choose the file) or from a terminal:

```sh
mysql -u root -p < database.sql
```

The script creates and selects the `nsbm_newsdesk` database. It is safe to import again; it creates missing tables and inserts categories without deleting existing data. It requires MySQL 8.0+ or a compatible MariaDB version.

The schema includes user accounts and roles, news categories and article review/publication workflow, comments, bookmarks, announcements, feed subscriptions, newsletter subscribers, and article-view analytics. No default administrator or password is created. When adding accounts, store a password hash generated by PHP's `password_hash()`; never store a plaintext password.

This SQL file provides the database foundation. The current HTML/JavaScript pages are static prototypes; PHP database connections and application queries still need to be implemented before the website reads or writes these tables.
